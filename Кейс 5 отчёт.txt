1. Функциональность
		Программа корректно вычисляет день недели, проверяет високосность, считает возраст
		Есть валидация даты через datetime.date()
		Красивый вывод даты звёздочками
	Проблемы:
		Нет проверки на будущие даты — можно ввести дату из будущего, программа выдаст отрицательный возраст
		Нет проверки на разумные границы — можно ввести год 1300 или 3000
2. Производительность 
	Программа работает быстро так как тут константный объёмом данных, производительность не критична.
3. Удобство использования (юзабилити)
	Проблемы:
		Нет повторного ввода при ошибке — при ValueError программа просто падает, пользователь должен запускать заново
		Нет возможности выйти — нет команды "выход" или "отмена"
		Вывод даты DDMMYYYY без разделителей — сложно читать (например, 01012000 вместо 01 01 2000)
4. Безопасность
	Проблемы:
		Нет защиты от некорректного ввода — ввод строки вместо числа вызывает ValueError
		Нет ограничения на диапазон значений — отрицательные числа, нулевой год и т.д.
5. Масштабируемость
	Проблемы:
		Нет модульности — всё в одном файле, нет разделения на логику и интерфейс
6. Сопровождаемость
	Проблемы:
		Нет тестов — нет unit-тестов для проверки функций
7. Переносимость 
	Всё в норме.
8. Качество кода 
	Проблемы:
		Глобальная переменная digits — лучше вынести в константу или класс
		Импорт datetime целиком — лучше from datetime import date
9. Тестирование 
	Проблемы:
		Нет unit-тестов вообще
		Нет тестов на ошибочный ввод
